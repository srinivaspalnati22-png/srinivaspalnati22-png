### RESQONE AI — Flagship Project

**"When every second matters, the system should already be thinking."**

RESQONE AI is my most complete build: an emergency intelligence platform designed around the Golden Hour, combining sensor data, real-time location intelligence, and coordinated response workflows.

- 🛡️ **Pre-Crash Safety Radar** — sensor-fusion based hazard detection
- 🚨 **Emergency SOS** — rapid alert and response workflow
- 🗺️ **Live Ambulance Tracking** — real-time location and routing
- 🏥 **Hospital Intelligence** — emergency hospital coordination
- 🩸 **Smart Blood Matching** — ABO/Rh compatibility-based donor matching
- 🐍 **Snakebite Assistance** — guidance and antivenom availability support
- 👥 **Emergency Network** — links citizens, hospitals, donors, and responders
