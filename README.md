## 02 — Featured Project

# RESQONE AI

### Emergency assistance. Connected technology. Real-world purpose.

</div>

RESQONE AI is an emergency assistance project designed around connecting people with useful emergency resources and support.

| Capability            | Purpose                                        |
| --------------------- | ---------------------------------------------- |
| Emergency assistance  | Help users access relevant support             |
| Hospital coordination | Support connections with medical facilities    |
| Ambulance tracking    | Assist with ambulance-location workflows       |
| Blood donor matching  | Connect blood requests with potential donors   |
| Snakebite assistance  | Provide a dedicated snakebite-support workflow |
| Volunteer network     | Support coordination with volunteers           |

**Technology stack**

`React` `Three.js` `FastAPI` `Supabase` `Python`
